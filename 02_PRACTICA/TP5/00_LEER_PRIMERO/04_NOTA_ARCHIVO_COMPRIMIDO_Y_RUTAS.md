# Nota sobre archivo comprimido y rutas

El paquete se distribuye como un archivo `.zip` generado en un directorio temporario. Ese lugar de generación no es la ruta definitiva de trabajo.

Luego de descargarlo, cada estudiante debe extraerlo y elegir una ubicación estable para guardar todo el material. Se recomienda evitar rutas muy largas, carpetas sincronizadas con problemas de permisos o nombres con caracteres especiales.

Ruta sugerida para Windows:

```text
D:\Temp\TP5_SIMULACION_INUNDACION_BAHIA_BLANCA
```
