Los scripts QGIS se ejecutan desde la consola Python de QGIS. Los scripts Python se ejecutan desde una consola de Windows. Ruta sugerida:

```text
D:\Temp\TP5_SIMULACION_INUNDACION_BAHIA_BLANCA
```

Dependencias Python:

```bat
cd /d D:\Temp\TP5_SIMULACION_INUNDACION_BAHIA_BLANCA\07_SCRIPTS_Y_PROMPTS

```
