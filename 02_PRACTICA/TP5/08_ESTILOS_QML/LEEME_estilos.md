# Estilos QGIS

Aplicar desde QGIS:

```text
Clic derecho sobre capa -> Propiedades -> Simbologia -> Cargar estilo
```

Estilos incluidos:

- `estilo_DEM_elevacion_comun.qml`: rampa común 0-80 m para comparar DEM.
- `estilo_hillshade.qml`: relieve sombreado.
- `estilo_profundidad_HECRAS.qml`: simbología para profundidad de inundación.

En `02_DATOS_BASE/DEM` se conservan también algunos `.qml` como archivos sidecar junto a los rásteres.
