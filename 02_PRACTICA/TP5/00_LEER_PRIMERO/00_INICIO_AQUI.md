# Inicio rápido - TP5

1. Extraer el ZIP en una carpeta de trabajo. Ruta sugerida:

```text
D:\Temp\TP5_SIMULACION_INUNDACION_BAHIA_BLANCA
```

2. Abrir el documento principal:

```text
01_DOCUMENTOS\00_Practico_Inundacion_BahiaBlanca_TP5_ESTUDIANTES.docx
```

3. Seguir el flujo QGIS -> HEC-RAS Mapper -> Python/HAND -> Orange Data Mining.

4. Tener presente que el ejercicio es una demostración pedagógica. La malla 2D incluida permite aprender el procedimiento en HEC-RAS, pero no debe interpretarse como una calibración final del evento real.

5. Los scripts y prompts se encuentran numerados en:

```text
07_SCRIPTS_Y_PROMPTS
```

## Sobre el ZIP

El archivo comprimido se genera en un directorio temporario. Después de descargarlo, cada estudiante debe elegir dónde conservar el material: disco local, carpeta institucional o unidad externa. Para evitar problemas con QGIS/HEC-RAS, se recomienda una ruta corta, por ejemplo `D:\Temp`.
