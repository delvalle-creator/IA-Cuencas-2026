# Flujo de trabajo

```text
DEM -> QGIS -> Terrain HEC-RAS -> Malla 2D -> Condiciones de borde -> Compute -> RAS Mapper -> Exportación Depth Max -> QGIS -> Python/HAND -> Orange Data Mining -> Interpretación
```

La parte HEC-RAS es el eje pedagógico del práctico. La parte HAND/Orange funciona como aproximación topográfica y analítica para comparar patrones, no como sustituto de una corrida hidrodinámica calibrada.
